# Reproduction and regeneration of the data

The files in `data/` are generated by `tools/exportar_para_lab.py` from the results folder of the Assignment 3 experiment (`experimentos_t3.py`): `runs/*.json`, `modelos/final_*.zip`, `linhas_de_base.csv`, `melhores_configs.json`, `info.json`, `hipoteses.csv`, `auc_curvas.csv` and `extra/*.csv` (the supplementary larger-budget experiment).

```bash
cd lab
python tools/exportar_para_lab.py                 # final export (requires all runs)
python tools/exportar_para_lab.py --so-extra      # only the supplementary experiment files (extra_*.csv, cartpole_*.csv) and indice.json
```

The script is idempotent (same input, same bytes). Sarsa weights are not saved by the experiment: the script deterministically retrains the best final seed with the same code, hyperparameters, budget and evaluation grid, and checks the result against the run JSON. `reference/python/barco_continuo.py` is a verbatim copy of the experiment module. Tests (`npm test`) compare the JavaScript environment, tile coding, the Sarsa update and the network inference with Python/PyTorch (`tests/reference.json`, generated by `tools/gen_reference.py`, and `data/paridade.json`, generated at every export).
